---
title: Azure AI Search
---
Azure AI Search is a fully managed search-as-a-service that supports keyword, vector, and hybrid
search over your own content. In agentic AI architectures it's commonly used as the grounding
layer: an agent issues a query, Azure AI Search returns the most relevant passages from an
indexed knowledge base, and those passages are fed back into the model's context as an
"observation" before it decides on its next action or produces a final answer.
